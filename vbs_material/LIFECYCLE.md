# 认证安装与客户端持久化：本地验证链路

2026-09-21。新增代码把 HPKE 材料通道、实际 PIR 服务器安装、服务器签名确认与客户端日志串起来。**真实 VBS enclave 已加载并完成公共测试种子的跨平台集成验证；可信客户端证明验证仍未完成，不能用于私密生产查询或报告完整 TEE 性能。**

## 每份材料的顺序

1. 客户端先把配置 ID 和材料 ID 写入私有日志，状态为 PENDING。生产调用者必须使用新的随机主种子和 ID；本测试适配器只能使用代码内已公开的测试种子。
2. 沿用 [CHANNEL.md](CHANNEL.md) 的证明验证接口、HPKE 请求、材料生成和 MAC 回执。默认真实验证策略仍返回 E_NOTIMPL。测试适配器明确不认证平台签名。
3. 客户端校验生成回执，提取材料摘要并计算生成回执摘要。此时 **不能查询**。
4. 客户端生成 32 字节随机 nonce，构造安装绑定：配置 ID、材料 ID、RawMaterial 摘要、生成回执摘要、nonce、服务器 epoch，各 32 字节，总计 192 字节。
5. `AuthenticatedInstaller` 检查配置、epoch、摘要、CRT 分支数、未使用分支和系数范围；将实际 RawMaterial 转换为原 PIR 材料并调用 `PreparedServer::Install`。只有安装成功后，才对确认头和完整绑定做 ECDSA P-256/SHA-256 签名。确认结构共 264 字节。
6. Windows 客户端使用**事先可信固定**的服务器公钥验签，并逐字节检查本次安装绑定。成功才允许一次性查询。测试中的密钥由可信测试程序在启动子进程时预置；这不是生产公钥分发机制。
7. 客户端日志写入 READY，再先持久化 RESERVED，才生成 LWE 查询。将完整查询密文字节写入 IN_FLIGHT 并 `fsync` 成功之后，才交给服务器。
8. 原服务器执行 PIR，客户端验证恢复记录与测试数据库一致。重试直接读取日志中的原查询字节，不再次生成 LWE 查询。结束后记录 DONE，并释放服务器材料。

查询索引仍在第 7 步选择。材料准备阶段不接收索引，因而不要求用户提前选定后续查询位置。

## 确认能证明什么

签名认证的是固定服务器公钥持有者关于这次安装的声明；它不是恶意服务器诚实保存、正确计算或未来可用性的证明。客户端将该声明与经过 MAC 认证的生成摘要相匹配。服务器不持有 HPKE 回执密钥，也不独立验证生成 MAC。

相同 ID、相同绑定的安装重试返回缓存的原签名回执；改变 nonce 等任何绑定字段都会被拒绝。缓存回执只确认过去的安装，不是查询时仍处于 READY 的新声明。客户端一次性状态和日志负责防止二次消费。

当前安装器密钥与 epoch 在进程启动时生成，不落盘；没有生产密钥管理、证书轮换或可信配置发布服务。安装器与原服务器应统一管理配置更新和服务生命周期，不能将公共测试程序视为多租户服务。

## 日志的故障边界

`ClientJournal` 使用客户端可信文件系统上的 0600 普通文件、独占锁、顺序号、前一条摘要和逐条 `fsync`。新建文件还同步父目录。日志不保存主种子、s、v 或明文索引；IN_FLIGHT 保存查询密文。

- 写盘失败后当前对象失效，禁止继续查询。
- 文件被截断、字段损坏、状态跳跃或已有文件变成零字节时拒绝打开，不自动清空或修复。
- 重启时由于不恢复密钥，所有 PENDING、READY、RESERVED、IN_FLIGHT 都持久化为 INVALID；只有原活跃进程可做精确重试。DONE/INVALID 的编号不能再次使用。
- 哈希链检测结构损坏；**不提供针对有写权限攻击者的认证、防删除、防克隆或快照回滚保护**。没有可信单调计数器。
- 当前文件上限 256 MiB、单条记录上限 2 MiB。到达上限时停止，未实现安全压缩和长期归档。

`validate_lifecycle.ps1` 在 functional 和 8mb 配置上各执行 3 次完整查询，核对所有 RLWE/Galois key 噪声关系、RNS 一致性、恢复结果、持久化精确重试、完成状态重载和复用拒绝。每个配置额外执行 4 种安装确认反例：签名篡改、nonce 替换、格式错误的固定公钥、版本篡改。安装前还检查错误 epoch/摘要拒绝，安装后检查相同回执重传及改变绑定拒绝。

`--native-lifecycle` 和 `--enclave-lifecycle DLL` 是测试宿主的二进制管道模式，只接受公开配置、固定测试编号和测试公钥。不会接收任意私密种子。后者确实调用 VBS API，失败不会回退到 native。

```powershell
& "$out\source\validate_lifecycle.ps1" -Backend enclave
```
